## Split files (ship with the repo, NOT the datasets) — in `~/dy/EmbodiedOcc2/data/`
- `data/occscannet/`: `train_final.txt` (**45610 frames**), `train_mini_final.txt` (5503), `test_final.txt`, `test_mini_final.txt`
  - each line = a frame, e.g. `gathered_data/scene0593_01/00069.pkl`
- `data/scene_occ/`: `train_online.txt`, `train_mini_online.txt`, `test_online.txt`, `test_mini_online.txt`
  - each line = a scene name, e.g. `scene0334_01`

## Scale (drives how much to preprocess)
- posed_images: **151300 jpg** across 1513 scenes (~100 frames/scene)
- Occ-ScanNet FULL split touches **681 distinct scenes**; MINI touches **80 scenes**
- So preprocessing ALL 1513 scenes wastes ~half the compute/disk → use `preprocess_subset.py`
  which only processes scenes listed in the given split txts (mini first, then full).

## How data flows into the model
- RGB `posed_images/scene/NNNNN.jpg` → image encoder + depth branch
- GT depth `posed_images/scene/NNNNN.png` (I;16) → depth supervision
- occ GT `gathered_data/scene/NNNNN.pkl` (local) · `scene_occ/*_package` (embodied)
- preprocess `.npy`: dataloader maps `posed_images/…` → `depthanything/…`, `normals/…`, `kappas/…`
  via regex (dataset_scannet_occ_openocc.py:139 / dataset_scannet_online_occ.py:130 & 122-128)
